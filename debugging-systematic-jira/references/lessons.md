## Jira 备注（2026-10-14 CP-58922）

- **不要写本机路径**（`.workbuddy/tmp/...`）：读者打不开；证据 = 内嵌截图 / 附件文件名 + 断言数字。
- **有截图默认嵌进备注正文**（html + `media-single`）；不要只挂附件让人点开。
- html 禁止 `<b>`（拒收），用 `<strong>`；已挂附件的同一 `fileId` 可直接嵌进原备注编辑，不必重传。
- Media `uploadCommand` 的 Bearer **禁止手抄**；Write 落盘后用 `scripts/jira-run-upload-command.mjs` 跑。
